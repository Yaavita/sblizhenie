# Третий лишний

Локальная игра для двоих за одним ноутбуком. React, TypeScript, Vite; без регистрации, сервера и внешних API.

## Запуск

```sh
npm install
npm run dev
```

Открыть http://127.0.0.1:5173. После установки зависимостей интернет не нужен.

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

В репозиторий включены портреты, готовые MP3 и пять исходных голосовых образцов в `assets/voice-references/`. Зависимости, сборка и промежуточные записи генерации исключены через `.gitignore`.

## Игры

- **Продай мне это**: шесть продаж нелепых товаров капризным покупателям. У продавца 45 секунд на рекламу, затем покупатель зачитывает неожиданный вопрос; на ответ — 30 секунд. Покупатель решает, купил бы он товар. Игроки чередуются, у каждого три попытки; первые две дают по баллу, последняя — два. Таймер не обрывает фразу. В финале — счёт, победитель или ничья и список сделок. Товары, клиенты и вопросы перемешиваются отдельно, без повторов внутри партии.
- **Один мозг на двоих**: восемь смешных вопросов с тремя вариантами ответа. Каждый выбирает тайно, стараясь совпасть с напарником. После второго ответа варианты раскрываются рядом; за совпадение — один общий балл. В финале — общий счёт и все восемь пар ответов. В партии нет повторяющихся вопросов, банк содержит 24 вопроса. Передача экрана и восстановление не показывают чужой выбор.
- **Музей неверных впечатлений**: каждый по очереди и отдельно готовит три подписи о себе. Другой выбирает одну фразу; автор рассказывает историю, после которой слушающий задаёт вопрос. Слушающий предлагает новую подпись, автор подтверждает её или просит уточнить. Шесть раундов чередуют игроков, каждый экспонат открывается один раз. В финале — выставка с исходными и новыми подписями, собственным названием и скачиванием в TXT. Подсказки учитывают степень откровенности. Таймера и вмешательств посреди истории нет; ведущий озвучивает открытие и завершение. Подготовка скрывается при паузе и восстановлении. Сохраняются введённые подписи, текущая фаза и готовая выставка; сами истории рассказываются вслух и не записываются.
- **Параллельные вселенные**: одна общая сцена, два отдельных рисунка и угадывание предметов в финале, около 58 минут. Каждый из пяти ведущих предлагает четыре основы: дом в разрезе с пустыми комнатами, сад, мастерскую, отель и другие места. Для всех 20 тем есть пример пустой композиции. Оба игрока рисуют одновременно: у каждого своё задание на предмет, а сам предмет он выбирает самостоятельно. Затем остальные четыре ведущих по очереди добавляют каждому ещё одно задание по своему характеру. Для каждой из 20 основ у каждого из пяти персонажей есть восемь подходящих заданий: всего 800. Двум игрокам выбираются два разных задания, смысловые повторы отфильтровываются; ни рассказов по очереди, ни споров, ни отмен нет. Время: 8 минут на начало, по 11 минут на каждого следующего ведущего и по 3 минуты на угадывание чужой картины. По таймеру переходы автоматические. Если оба закончили раньше, можно сразу перейти дальше кнопкой, без подтверждения. Это работает и при угадывании. Есть пауза. Вся история доступна в одной ленте. В финале автор молча показывает картину; другой выбирает три задания из списка именно этого автора и ищет на рисунке предметы, которые были ответами. Затем автор объясняет свой выбор. Итог сохраняется с названием, заметкой и экспортом TXT. Новые реплики текстовые, со звуковым сигналом. Выбранные задания сохраняются целиком, поэтому после обновления банка вопросы партии остаются прежними. Начатые сохранения версии 2 получают исходные вопросы прежнего банка; новые партии используют банк из 800 заданий. Старые десятиэтапные сохранения продолжаются по прежнему сценарию.
- **Культ двух человек**: создание веры, пять решений, ересь, голод, политический договор и последствия. Четыре ключевые развилки дают 81 комбинацию, финальное решение определяет наследие.
- **Аукцион ценностей**:10 случайно перемешанных лотов из 60; по 15 собственных историй у Шума, Момо, Архивариуса и Нуар. Основного ведущего нет. Перед каждым лотом неограниченное время подумать; «Далее» открывает торги. У каждого 100 монет, открытые ставки по очереди с шагом 1 и 30 секундами на ход. Первая ставка обязательна. Победитель платит в банк за рассказ другого. При нулевом балансе вход автоматически переходит к другому игроку. Если оба кошелька пусты, банк выдаёт одну монету на вход, чтобы игра продолжалась.
- **Чужие секреты**: два разных цельных расследования, асимметричные роли, три порции личных улик, общая хронология, заключение и доказанная развязка.

В трёх новых играх игрок 1 всегда слева, игрок 2 справа. Текущий ход выделен, на экране одно действие. В музее рассказ и вопрос разделены: сначала один рассказывает, затем другой задаёт вопрос, после чего пишет новую подпись. У всех трёх игр сохраняются прогресс и итоговый экран. Интерфейс рассчитан на ноутбук 1440×900.

Рисование рассчитано примерно на час, остальные основные сценарии — на 20–30 минут; «Продай мне это» — на 10–15, «Один мозг на двоих» — на 5–10. Разговор можно продолжать свободно. Личные ответы можно пропускать. В аукционе голос Случая вмешивается между историями: с ростом разницы балансов вероятность увеличивается от 8% до 66%, максимум 5 появлений за партию. Он может обменять кошельки или предложить дополнительный рассказ за 15 монет из банка. Награду одобряет другой игрок; повторное начисление исключено. Эти условия не раскрываются на стартовом экране.

## Степень откровенности

Уровень каждого игрока выбирается отдельно; в партию попадает меньший из двух. «Бережно» — личные истории без интимных тем; «С искрой» — романтика и флирт; «Откровенно» — желания, притяжение и уязвимость.

У всех 60 аукционных лотов по три написанных варианта вопроса, у семи вопросов Случая — тоже. Состав ведущих и экономика от уровня не меняются. В рисовании меняются задания и темы каждого этапа. В культе романтические обряды или исповеди желаний становятся частью конфликта, сохраняя последствия решений. В двух детективах меняются завязка, личные тайны свидетелей и мотивы; физические улики, время, виновник и проверка версии остаются согласованными. Ограничения ведущего дополняют выбранную тему. Интимные вмешательства отфильтровываются по уровню. Новые варианты находятся в `src/content/intimacy.ts` и `src/content/auctionIntimacy.ts`.

## Голоса

73 реплики прежнего каталога записаны пятью одобренными голосами. Проигрываются локальные MP3: `public/audio/voices/`, каталог `src/audio/voiceManifest.json`. Синтеза речи и сетевых запросов к сервисам в игре нет. Новые диалоги рисования пока текстовые, со звуковым сигналом. В прежних сценариях задания на экране остаются текстовыми; озвучены реплики ведущих, вмешательства, ответы персонажей и появления Случая в аукционе.

На время речи таймер ждёт. Пауза останавливает запись и таймеры, продолжение сохраняет позицию. Новая реплика прерывает предыдущую; возврат к предыдущему ведущему не повторяет уже услышанный текст. Под портретом — повтор реплики; звук выключается кнопкой в шапке. Экран прослушивания проб удалён, одобренные исходники остаются в `assets/voice-sources/` и `assets/voice-references/`.

Генерация работает отдельно от приложения: `scripts/build-voice-catalog.mjs`, `generate-game-voices.py`, `finish-game-voices.py`. Используется локальная Qwen3-TTS Base4bit с клонированием исходных проб; mlx-whisper размечает слова для смысловых пауз. Для повторной записи нужны Python3.12, mlx-audio, mlx-whisper, soundfile, ffmpeg и загруженные модели. Для игры они не нужны. Промежуточные WAV и разметка лежат в `assets/game-voice-sources/`.

## Состояние и приватность

`src/content/` содержит сценарии,60 лотов, вопросы и характеры; `src/engine/engine.ts` управляет этапами и стеком вмешательств; `src/engine/director.ts` подбирает вмешательства по текущему этапу; `src/engine/auction.ts` содержит отдельный чистый движок торгов. `src/hooks/voice.ts` отвечает за аудио, `src/components/` — за интерфейс.

В культе, детективах и старых сохранениях рисования основной ведущий остаётся на всю партию. Корневые вмешательства разделены 90 секундами активного времени, максимум 5 появлений, глубина 2, более высокий приоритет для перебивающего. Завершение и отмена восстанавливают приостановленное время без перерасхода. Пауза и открытие условий останавливают все таймеры, речь и новые события. Вкладка в фоне ставит игру на паузу.

«Условия» содержит посещённые задания, принятые решения, изменения правил и историю торгов с денежными событиями. Личные улики перечитываются через закрытую передачу экрана. Сведения другого игрока не остаются в DOM после передачи. Предпочтения и секреты читаются по очереди; откровенность определяется меньшим из двух выбранных уровней.

Сессия сохраняется в LocalStorage и восстанавливается на паузе с балансами, текущим ходом, вопросом, решением по награде и стеком вмешательств. Повреждённые сохранения отклоняются. Старый аукцион с закрытыми ставками не переносится на новую экономику; остальные прежние партии восстанавливаются.

## Проверка

Тесты покрывают вложенные отмены, точный возврат времени, приоритеты и лимиты, паузу, невозможные тики, восстановление, развилки культа и факты детектива. Для аукциона проверяются подготовка без таймера, обязательный вход, нулевые кошельки, автоматические ставки, таймауты, отсутствие перерасхода, частота Случая, обмены и однократные награды. Каталог озвучки проверяется на полное покрытие и существование файлов.

98 автоматических тестов проходят. Сценарная проверка включает 216 сочетаний романтических веток культа, совместимость ограничений пяти ведущих и защищённые этапы без вмешательств. В Chromium пройдены 9 полных неаукционных партий (три игры × три уровня, 90 этапов) и аукцион из 10 лотов. Проверены 73 аудиофайла, запуск после обычного клика, пауза записи, продолжение и озвученный вложенный спор с возвратом времени. Портреты оригинальные, локальный атлас в `public/assets/`; Safari-фильтр, скрывавший их, удалён. Проверка в самом Safari недоступна.

Для музея отдельно проверены приватная подготовка трёх разных подписей, шесть раундов с чередованием ролей, уточнение и подтверждение подписей, запрет повторного экспоната и восстановление сохранений. В Chromium пройдена полная партия: выбор игры, подготовка и передача экрана без чужих подписей в DOM, перезагрузка, пауза, галерея из шести экспонатов и скачивание TXT. Целевой экран — ноутбук 1440×900: основные действия видны без прокрутки, подсказки расположены рядом с полями. Проверены отсутствие горизонтального переполнения и ошибок консоли.

Для коротких игр дополнительно проверены стабильное перемешивание без повторов, разный порядок одинаковых вариантов у двух игроков, закрытое чтение и восстановление, очередность продавца и покупателя, мягкие таймеры, пауза и подсчёт очков. В Chromium на 1440×900 пройдены все восемь раундов «Одного мозга» и все шесть продаж, включая отказ в покупке и двойные баллы. Итоги обеих игр восстановлены после перезагрузки; основные кнопки доступны без прокрутки, ошибок консоли нет.

Для нового рисования проверяются все пять ведущих и 48 вариантов: общая основа, разные личные задания, по одному появлению каждого персонажа, 58 минут суммарно, полное автоматическое прохождение, досрочные переходы и восстановление на каждой реплике. Финальные вопросы сопоставляются с точными заданиями другого игрока. В Chromium на 1440×900 проверены выбор всех 20 тем с примерами композиции, одновременное рисование, автоматический приход ведущего, раздельные задания, пауза, история, угадывание по исходным вопросам, восстановление и редактирование итогов, экспорт TXT. Ошибок консоли и горизонтального переполнения нет.
